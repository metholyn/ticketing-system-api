# About

This project is a university assignment for the course "Professionally-oriented
practicum in a foreign language", content module 2 ("Documenting software
code"), practical task "Documenting an API with OpenAPI and Zudoku".

**Author:** Mark Pereverzov
**Subject area (variant 14):** Ticketing system — an event ticketing system,
entities `Event` and `Ticket`.

## What was done

1. Designed a REST API for the Ticketing System domain model (CRUD for `Event`
   and `Ticket`, auxiliary resources `Organizer`, `Venue`, `User`).
2. Described the API in the OpenAPI 3.1 format (`openapi.yaml` / `openapi.json`),
   generated automatically from the code with FastAPI.
3. Generated a Python SDK client with the `openapi-python-client` generator
   (`sdk/python-client/`).
4. Uploaded the code, the OpenAPI document and the SDK to a GitHub repository.
5. Created this documentation site with [Zudoku](https://zudoku.dev), deployed
   to GitHub Pages.
