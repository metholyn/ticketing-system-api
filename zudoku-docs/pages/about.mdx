# About

Цей проєкт — навчальна робота з курсу "Професійно-орієнтований практикум іноземною мовою",
змістовий модуль 2 ("Документування програмного коду"), практичне завдання
"Документування API за допомогою OpenAPI та Zudoku".

**Автор:** Марк Переверзов (Mark Pereverzov)
**Предметна область (варіант 14):** Ticketing system — система продажу квитків на події,
сутності `Event` та `Ticket`.

## Що зроблено

1. Спроєктовано REST API для доменної моделі Ticketing System (CRUD для `Event` та `Ticket`,
   допоміжні ресурси `Organizer`, `Venue`, `User`).
2. API описано в форматі OpenAPI 3.1 (`openapi.yaml` / `openapi.json`), згенеровано автоматично
   з коду за допомогою FastAPI.
3. За допомогою генератора `openapi-python-client` згенеровано Python SDK-клієнт
   (`sdk/python-client/`).
4. Код, OpenAPI-документ та SDK завантажено в GitHub-репозиторій.
5. Створено цей проєкт документації на базі [Zudoku](https://zudoku.dev), задеплоєний на
   GitHub Pages.
