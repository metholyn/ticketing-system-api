# Ticketing System API

A REST API for an event ticketing system. Main entities:

- **Event** — an event that tickets are sold for (date, venue, organizer, price, number of seats).
- **Ticket** — a ticket linking a specific event to a specific user (status: `reserved`, `paid`, `cancelled`).

The auxiliary entities `Organizer`, `Venue` and `User` are used as foreign keys for `Event` and `Ticket`.

The full API specification is available in the [API Reference](/api) section.
