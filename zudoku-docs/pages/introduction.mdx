# Ticketing System API

REST API для системи продажу квитків на події. Основні сутності:

- **Event** — подія, на яку продаються квитки (дата, майданчик, організатор, ціна, кількість місць).
- **Ticket** — квиток, що зв'язує конкретну подію з конкретним користувачем (статус: `reserved`, `paid`, `cancelled`).

Допоміжні сутності `Organizer`, `Venue`, `User` використовуються як зовнішні ключі для `Event` та `Ticket`.

Повна специфікація API доступна в розділі [API Reference](/api).
