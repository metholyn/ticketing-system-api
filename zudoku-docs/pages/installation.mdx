# Installation

## 1. Running the API itself

```bash
git clone <URL_OF_THIS_REPOSITORY>
cd ticketing-system-api
pip install -r requirements.txt
uvicorn api.main:app --reload
```

The API will be available at `http://localhost:8000`, the Swagger UI at
`http://localhost:8000/docs`, and the raw OpenAPI specification at
`http://localhost:8000/openapi.json`.

## 2. Installing the generated SDK (Python)

The SDK client is generated with
[`openapi-python-client`](https://github.com/openapi-generators/openapi-python-client)
from the `openapi.yaml` file (task item 4) and lives in the `sdk/python-client` folder.

```bash
cd sdk/python-client
pip install .
```

Once installed, the `ticketing_system_api_client` package can be imported in any
Python project:

```python
from ticketing_system_api_client import Client, AuthenticatedClient
from ticketing_system_api_client.api.events.list_events_events_get import sync as list_events

client = AuthenticatedClient(
    base_url="http://localhost:8000",
    token="demo-key-123",
    prefix="",
    auth_header_name="X-API-Key",
)
events = list_events(client=client)
print(events)
```

## 3. Where to find the code and the SDK

| What | Where |
| --- | --- |
| API and domain model source code | `app/`, `api/` |
| OpenAPI specification (YAML/JSON) | `openapi.yaml`, `openapi.json` |
| Generated Python SDK | `sdk/python-client/` |
| Zudoku documentation project | `zudoku-docs/` (this site) |

Links to the repository with all the code and the SDK are on the [About](/about) page.
